# 五菱汽车车控

#### Description
基于https://github.com/hasscc/wuling开发的五菱新能源独立车控APP，无需Home Assistant环境，直接对接官方车联网接口，为五菱车主提供全维度车控体验。
 
核心功能涵盖：远程控制、蓝牙无感控车、电池/里程全状态监控、高德定位导航找车，同时支持API配置、主题设置等个性化操作。
 
开源无广告，数据直连官方接口，安全可控，欢迎Star与贡献
